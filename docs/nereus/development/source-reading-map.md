## Review order {#review-order}

For a change that touches several layers, inspect in this order: public value/contract, metadata
authority, provider identity and response-loss behavior, adapter projection, then runtime lifecycle
and tests. If a lower layer starts importing an upper protocol type, stop and revisit the boundary.
